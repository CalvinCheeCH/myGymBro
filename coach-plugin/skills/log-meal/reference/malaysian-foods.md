# Malaysian food reference: calories and protein

Typical values for common Malaysian foods, for portion-realistic estimates.
Every number is an estimate from public nutrition sources and typical hawker,
mamak, and kopitiam portions; treat it as a starting point, not a lab result.

## How to use this reference

- Use this reference only when the user's actual dish or eating context matches
  the foods below. It does not establish their location, language, or dietary
  restrictions, and is not a default reference for unrelated meals.
- Match the dish first, then adjust for **portion cues** the user gave ("nasi
  sikit", "extra kuah", "shared"). Adjust calories roughly proportionally;
  protein follows the meat/fish/egg part, so scale it with the protein item,
  not the whole plate.
- When a dish is not listed, estimate from its closest cousin plus its cooking
  method (deep fried adds roughly 100 to 200 kcal over steamed or grilled).
- State estimates as a range when unsure (for example "around 650 to 750 kcal"),
  and log the midpoint unless the user corrects you.
- Nasi campur and kandar-style plates: build the estimate from components using
  the component table at the bottom instead of guessing one number.

## Hidden calorie watchlist (mention lightly, never lecture)

- Santan (coconut milk): curries and rendang carry most of their calories here.
- Condensed/evaporated milk: teh tarik, kopi C, Milo; "kosong" versions cut
  roughly 100 kcal per drink.
- Deep frying: goreng items run 100 to 200 kcal above their steamed/grilled
  equivalents.
- Sambal, kuah, and sweet sauces: easy extra 50 to 150 kcal per plate.
- Nasi lemak peanuts and ikan bilis are small but calorie dense.

Respect dietary restrictions the user actually stated. Do not infer a halal
requirement or any other restriction from a dish name or regional context.
